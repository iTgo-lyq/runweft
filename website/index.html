常见问题

开始前，
你可能想知道。

需要同时安装 Codex 和 Claude Code 吗？

不需要，使用其中一种即可。同一种工具可以承担不同任务；两种都已接入时，也可以从 Codex 委派给 Claude Code，或反过来。

需要先准备服务器或 Hub 吗？

第一次使用可以让 Agent 在本机启动 Hub，它负责管理任务、机器和 Agent 配置。团队已有 Hub 时连接它的地址即可。

任务会改动我正在写的代码吗？

共享目录中的任务直接访问当前项目，所以首次建议明确要求只读评审。要隔离代码改动，可以选择独立工作目录（Git worktree）；它从已提交的版本开始，不会带上主目录未提交的内容。“只读”是任务指令，执行权限沿用原生工具设置。

完成的代码会自动合入或推送吗？

不会。Runweft 保留代码成果和工作目录，主 Agent 可以取回并审查。是否合入、如何处理冲突和何时推送，由你和主 Agent 决定。

已有的配置和后续任务怎么办？

安装 MCP 时会备份配置，保留其他 MCP 和原生设置。已完成的任务可以继续追加要求，优先复用原会话与工作目录。配置位置、升级和卸载见诊断与维护。
