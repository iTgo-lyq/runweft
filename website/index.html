常见问题

开始前，
你可能想知道。

需要同时安装 Codex 和 Claude Code 吗？

不需要。安装并登录你要使用的原生工具即可。宿主和执行 runtime 可以不同，例如从 Codex 委派给 Claude Code；使用哪一个由 Agent 的 runtime 绑定决定。

本地任务必须使用 Git 吗？

共享目录模式可以没有 Git。本地独立 worktree 和所有远端任务都要求主工作区受 Git 管理；准备使用已提交的明确基线，不会自动带上主目录未提交的改动。

任务完成后，代码会自动合入吗？

不会。Runweft 保留成果和 worktree，提供报告与取回入口。代码审查、merge / cherry-pick、冲突处理和 push 由主 agent 或你决定。

配置、会话和数据保存在什么地方？

Runweft 默认使用 ~/.runweft，执行 runweft paths 查看实际位置。Codex / Claude 的原生配置与会话沿其已有位置保存。安装 MCP 会先备份相关配置，其他 MCP 和原生设置保留。

可以继续已有任务吗？子 agent 还能再委派吗？

可以继续已有任务，Runweft 优先复用原生 session 与保留的 worktree。Runweft 子执行会禁用 Runweft MCP，避免递归委派；原生工具自己的内置 subagent 能力保持不变。
