# Runweft

让 Codex 和 Claude Code 通过 MCP 委派任务，以 HAPI 内置执行能力运行子会话。

通过 Hub 的身份、空间和中心 Agent 配置协作，支持本机共享目录、独立 worktree、远端执行及附件与代码成果回收。用户通过对话与产品 Skill 安装、接入和维护。

- [产品官网](https://runweft.pages.dev/)：介绍与上手指南。
- [使用说明](docs/usage.md)与[产品 Skill](.agents/skills/runweft/SKILL.md)：安装、配置、委派和维护。
- [公开 Skill 仓库](https://github.com/iTgo-lyq/runweft-skill)：独立安装入口；本仓库的 `.agents/skills/runweft/` 由 CI 单向同步到该仓库。
