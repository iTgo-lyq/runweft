# 任务附件与持久交付

> 状态：已确认
> 规模：大型
> 更新：2026-09-29
> 确认依据：用户已确认中心管理附件、启动前准备、离线取回，并授权自主细化各 Change、一次 iclaude Plan 评审后逐任务执行。本次默认值与命令按该授权确定，尚未实现。

## 交付目标

主 agent 或操作者通过一个 Runweft CLI/MCP 上传文件、带入任务并取得成果。输入准备好才启动子会话，已交付文件在执行机离线后仍可从中心下载。传输失败独立处理，不重跑模型。

方案依据见 [Research](research.md)，正式设计见 [Technical](technical.md)、[文件与传输契约](artifact-contract.md)。[Design](design.md)仅保留前期讨论。

## 行为变化

### ADDED `artifacts/inputs`：启动前输入

- 无活跃会话也可上传、查看、下载文件。统一命令返回 artifact ID、名称、字节数和 SHA-256；原请求重试可查询相同对象。
- spawn 和 next 可携带文件引用及逻辑名称，冻结到各自轮次；本轮消息说明实际输入路径。MCP 文件源/目标限定宿主 cwd，CLI 显式路径沿操作者权限。steer 保留现有文字追加，不在正在执行的轮次里改输入文件。
- Runner 在新建/续接原生执行之前下载、校验必需输入；失败没有模型进程，不能让 agent 用 prompt 补做准备。输入位于受控数据根，避免污染主仓库和 Git 成果。
- 任务关联沿现有 parent/namespace 校验；知道 task ID 或 artifact ID 不等于有权限。

### ADDED `artifacts/delivery`：持久输出与补交

- 发起任务时可声明多个工作区内的输出文件相对路径。每轮原生停止确认后，程序收集这些文件；只处理显式文件，不递归扫描目录、home 或依赖。
- 完成中心校验和持久发布才声明可下载。清单逐项记录成功、缺失或错误，保留原生报告和 Git 成果的独立状态；部分交付附明确 attention，保留既有轮次执行结论。
- 已捕获的文件传输失败保留本地候选，可重试传输而不再次启动模型；响应不明确时查询原操作。补交发布新的清单版本，旧版本和已发布字节不变。
- 主 agent 也可在轮次结束后显式收集遗漏文件，标明补交的实际时间；不把后改文件假称为原轮次结束时的快照。当前任务仍有执行或准备时不收集。
- 传输仍在进行或结果未知时不开放下一轮；确定的部分交付可结束本轮并返回可处理状态，保留重试候选。后续轮次不以旧路径重新抓取旧成果。

### ADDED `artifacts/retention`：清理、配额与可理解的配置

- 本地字节保存在本机 HAPI 数据根，Hub 模式保存在所选 Hub；Runner 输入和未完成交付候选统一位于连接的 HAPI 数据根。paths/doctor/使用说明展示这些位置。
- 默认单文件上限 512 MiB、每 namespace 保留与预约总额 10 GiB，通过 server.artifacts 配置本机托管服务，Hub 客户端查看服务实际限制。超过限制明确说明限制和下一步，不静默截断或绕过配额。
- 上传中对象不开放下载；已发布对象不可覆盖。文件名不决定内部存储键；自动落地/收集拒绝绝对路径、`..`、重复名称和逃逸 symlink。
- 任务输入、成果清单及恢复用途的引用阻止普通删除和清理。完成任务不自动删除唯一副本；清理为显式命令，默认预览，未引用发布对象满 7 天、未引用上传预约满 24 小时才进入批量候选。
- 提供查看引用、释放已结束轮次附件留存及明确删除的路径，避免配额满后无处处理。释放不删报告、Git ref 或工作区，也不声称可继续下载已清理附件。未完成传输/活跃轮次/恢复引用不能普通释放。

## 验收标准

- [ ] R1：无活跃会话的真实 CLI 上传/读取/下载，local 与同机 Hub 均通过，内容与 hash 相符。
- [ ] R2：真实 Codex/Claude 共享任务在启动前得到文件；新增轮次正确续接，worktree 组合正确；必需输入失败无原生启动。
- [ ] R3：错误 hash/长度、未完成上传、配额不足不产生可下载对象；超过原 HTTP 68 MiB 上限的合理文件确实可流式传输。
- [ ] R4：断线或发布响应丢失后查询/重试同一操作，已发布字节不可改写，任务输入不会重放。
- [ ] R5：多项输出、缺失和部分交付可见；补交形成新版本，旧版本不变；执行机停机后仍可下载中心已发布文件。
- [ ] R6：沿原有认证拒绝越权；自动路径/symlink 逃逸、目录和不稳定文件如实失败，不上传隐含目录内容。
- [ ] R7：引用中的对象不能普通删除；显式释放/删除/过期清理和配额释放可验证，删除返回明确失效状态。
- [ ] R8：真实两 MCP 宿主调用附件和任务能力；候选包安装后可运行，配置/诊断/备份说明完整，临时验证产物不入库。
