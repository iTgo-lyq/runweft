## 交付目标

保留现有官网视觉，让首次访问者看懂产品用途，知道把什么交给 Agent、自己需要确认什么，并能完成第一次只读委派。

## 关键决策与风险

- 先明确 Codex / Claude Code 的任务委派用途；不用抽象口号代替产品定义。
- 本机共享目录只读评审为入门例子；远端、独立 worktree、权限治理和维护为进阶内容。
- 新手按一条 Agent 辅助接入路径阅读；手工命令可展开，接入提示和下一步各有明确结果。
- 保留权限及 Git 事实，避免把接入成功写成模型任务成功；不承诺自动合并或同步本机未提交代码到独立目录。

- 接入提示止于装好 MCP 并提醒重开；委派示例在重开后的新对话中发送。首屏在 1280×800 与 390×844 可见产品定义及主 CTA。
