# Hub 后台与 Agent 接入实施计划

> 状态：执行中
> 来源：[Requirement](requirement.md)
> 技术方案：[Technical](technical.md)
> 执行模式：同一工作区串行、逐任务独立提交；实施前一次 iclaude 评审。

## 交付目标

交付完整 Hub 资源后台与产品 Skill，用户通过对话完成接入，通过 Web 查看和维护实际授权资源。前五阶段已经验收，不重开实现；最终四平台新版发行由父 Change 在本阶段归档后执行。

### T1 服务端能力与原生页面交接

- 状态：已完成
- 交付：空间/成员/邀请操作权限 DTO、本人任务只读详情、保留空间/期限的 HAPI 短凭据交换和明确深链接、共享执行终端权限收紧。
- 依赖：已归档前五阶段。
- 验收：客户端不推导治理权；他人任务/私有数据不可读；短凭据不能无限刷新或扩大空间，机器/任务不能登录后台；不改 HAPI。
- 验证：聚焦 API、跨用户/空间、过期/撤销、子路由与受管会话控制回归；typecheck。

### T2 后台外壳与机器/Runtime

- 状态：已完成
- 交付：统一导航与身份/空间、机器/runtime 管理；浏览器模块按静态 ES module 内嵌服务，避免单文件膨胀。
- 依赖：T1。
- 验收：所有操作消费领域 permissions/API；空态/失效/离线可解释；刷新和切换无旧身份数据；桌面/窄屏/键盘可用。
- 验证：Playwright 机器/runtime 流程、权限按钮与直接 API、截图审查及 typecheck/build。

### T3 Agent、仓库与本人选择

- 状态：进行中
- 交付：完整 Agent 定义/版本/分享与治理，仓库目录/别名/登记、本人选择/override/解析。
- 依赖：T2。
- 验收：成员和管理员不取得他人私有内容或编辑权；同仓库个人配置独立，失效不自动回退。
- 验证：Playwright 完整编辑/分享/治理/选择和直接越权，聚焦领域测试。

### T4 任务详情与原生页面

- 状态：待开始
- 交付：任务过滤分页/轮次/配置/报告/成果、HAPI 同身份详情/文件/审批、独立标签页登录与到期引导。
- 依赖：T3。
- 验收：总数只含本人任务；不泄露凭据，刷新不串身份；原生页面过期可返回 Hub。
- 验证：Playwright 多身份、多标签、原生深链接与拒绝终端，报告分页及截图。

### T5 产品 Skill 与 Agent 优先使用路径

- 状态：待开始
- 交付：仓库产品 Skill、完整接入/登记/配置/诊断/升级说明、网站 Agent 主流程和 Skill 下载；不修改开发者全局配置。
- 依赖：T4。
- 验收：说明与 CLI 契约一致，凭据只经 Web 确认交接；安装到专用两宿主配置且保留其他设置；不声称旧包包含新版功能。
- 验证：Skill 结构校验、独立 Agent 场景验证、安装/更新/卸载和首次委派、官网构建/链接/Playwright。

### T6 阶段 6 自动验收

- 状态：待开始
- 交付：需求逐项证据、实际模型/会话、已知外部边界；所有本地领域功能完成。
- 依赖：T1–T5。
- 验收：全部阶段 6 需求通过自动验收，无转交阶段 7 的缺失领域行为；不更新在线部署。
- 验证：bun run typecheck、bun run test、bun run build、真实 Hub/Runner/浏览器/两宿主接入；随后 Specs 同步与独立归档。
