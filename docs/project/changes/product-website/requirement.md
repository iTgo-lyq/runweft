# 产品官网与安装指南

> 状态：进行中
> 规模：中型
> 更新：2026-09-30
> 确认依据：用户直接要求编写产品官网、介绍安装使用；沿 AGENTS.md 既有自主工程决策、一次 iclaude 评审与本地自动验收授权。

## 目标

让首次接触 Runweft 的开发者理解产品用途，并从官网取得正确的平台包、接入 Codex/Claude Code、配置执行目标并完成第一次委派。官网作为现有仓库独立的静态前端维护，沿已实现的 CLI/发行契约，不修改执行底座或已冻结的 1.0.0 产物。

## 行为变化

### ADDED

`website/product`：中文产品首页，介绍两种原生 Agent、本地/远端协作、工作区准备、成果取回与看板；交互示意明确标注为示例。提供四平台选择、真实下载链接、对应校验文件和可复制安装命令。

`website/guide`：独立上手页，包含前置条件、安装启动、全局 MCP、机器/runtime/Agent 的独立配置、项目中的首次任务、Hub 部署、数据与排错。完整手册随静态产物提供，导航支持子路径部署和移动端。

## 边界与依据

- [发行产物](../../specs/release/distribution/spec.md)、[安装](../../specs/installation/cli/spec.md)、[MCP](../../specs/installation/mcp/spec.md)和 [使用说明](../../../usage.md)为内容来源；1.0.0 未公开发布 npm，不提供不可用的公共 npm 安装命令。
- 页面提供本次已构建平台包；Mac 未签名/实机待用户验证、Linux arm64 当前仿真、物理跨机未实测的范围明确可见，不做虚假背书。
- 不增加账号、模型执行、数据采集或付费流程。没有新域名/公开发布指令，交付可部署静态目录和本地预览，不上传任何产物到外部服务。

## 验收标准

- [ ] 首页具备明确产品定位、能力与协作流程、下载安装和指南入口。
- [ ] 四平台下载内容与 1.0.0 index/hash 相符；单文件校验可独立完成，不要求下载其他平台。
- [ ] 安装、MCP 和首次任务示例对应当前 CLI，分别解释机器/runtime/Agent，不把握手宣称为模型成功。
- [ ] 平台切换、复制、导航、FAQ 和本地/远端示意可用，示意不是在线任务状态。
- [ ] 手机/桌面、键盘、reduced motion 和无 JavaScript 基本阅读可用，无横向页面溢出或浏览器错误。
- [ ] 独立构建和预览可复现；产物含实际下载文件及手册，核心 CLI 产物不变。
