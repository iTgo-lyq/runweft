# 前端发布输入完整性

用户要求将前端重构合入 main，并确认 npm 和公开 Skill 已发布最新版。本 Change 延续 hub-glass-prototype，补齐发行前发现的输入校验缺口，根版本准备为 1.2.1。

Hub 资源构建依赖 `packages/ui/build.ts`、组件与样式，以及根 `tsconfig.json` 的 JSX 和路径解析配置。现有冻结输入清单未覆盖这些文件，允许 UI 已变化时复用旧候选或模型验收报告。

## 方案与范围

将 UI 构建代码、UI 源码、TypeScript 配置和 Tailwind 扫描使用的根 `.gitignore` 纳入共用的 packageInputs，使候选复用、公开恢复和原生报告校验一起拒绝输入变化。通过独立临时 Git 仓库验证修改、已提交变化和新增未跟踪 UI 文件均被拒绝；不将独立原型或工程说明纳入产品输入。

只修改发行输入清单、相应测试、版本与当前发行规格，属于 small；不改变产品接口和数据格式。发布沿用现有发行工作流与五项原生模型验收，实际发行结果保存在 Actions，不新增逐版本发行报告。用户已明确授权 main 合入、最新版发布与历史数据清理；本机清理仅按确认的 Runweft 归属执行。

## 验收

- UI 构建、组件、样式、TypeScript 配置和根忽略规则发生变化后，旧候选必须拒绝复用；新增 UI 文件同样被识别。
- 相同产品输入、纯工程文档变化可以复用候选。
- 工具测试、文档/流程校验通过，独立评审确认冻结边界完整。
- 版本为 1.2.1；正式发布仍须完成发行规范要求的独立门禁。
