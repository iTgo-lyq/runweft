## 交付目标

官网同时说明 Runweft 的原生任务委派方式及已复用的 HAPI 会话、审批、文件和续接体验，仍沿用简明上手路径。

## 关键决策与风险

- 全部面向用户的文字由 iclaude 编写，主 Agent 只核对事实与集成。
- 浏览器审批与文件查看有真实开放入口；HAPI 全部功能不自动等于 Runweft 能力。
- 手机访问需 Hub 网络可达；委派的输入/续接仍经主 Agent/Runweft，不暗示网页任意接管会话。
- 不扩大 runtime 支持、配置继承或无数据外发承诺，保留现有视觉与 1.1.3 安装。

- 已完成 iclaude Plan 评审，采纳在线 session 文件读取、条件审批、手机身份/网络、网页输入限制、全文作者追溯与首屏基线核对；不新增图片或 HAPI 外链。
