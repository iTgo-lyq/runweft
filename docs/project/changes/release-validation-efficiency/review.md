## R1 公共矩阵缺少上传前的真实运行

首轮指出空参数预检只跑 inline。新增 `verify-run-id` 严格复用原候选描述、上传前成功证据和冻结输入，跳过构建/上传/晋级/部署；工作流与脚本均拒绝写操作。新增入口经独立定向复核通过，公共验收 38372185710 的全部 11 个必需 job 与 summary 成功，晋级和官网部署均跳过。失败时保留原候选，修复后只读续验；真实发布后如需恢复，沿用 release-tag + 原 source-run-id，不重发同版本。

## R2 Mac Intel 拆分收益尚未证实

原 1.1.5 在传播延迟场景下由 Linux/storage 决定总墙钟，不能直接声称 Mac 拆分缩短那次发布。新只读同候选验收没有传播等待，Mac Intel 卸载成为最后结束的必需 job，安装/卸载均独立通过。保留拆分；原串行 311 秒与新拆分最长 154 秒的差也包含宿主/准备波动，不全部归因于优化。最终收益以新版本正式发布分布记录。
