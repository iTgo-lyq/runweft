# 官网 HAPI 会话截图实施计划

> 来源：./requirement.md
> 技术方案：./technical.md
> 状态：执行中
> 执行模式：逐任务提交

## 交付目标

在现有官网 HAPI 说明中展示 HAPI 官方会话记录与代码查看截图，使读者直观看到界面。

## 关键决策与风险

- 全部新增展示文字交给 iclaude；官方原图逐字节校对并注明来源，避免将 HAPI 全部功能当作 Runweft 已接通能力。
- 仅发布审看后的 WebP，不复制环境数据或登录凭据；部署白名单不放宽。
- 保留首屏、版本与核心使用路径；两图总大小目标低于 500 KiB。

## 任务

### T1 截图与官网展示

- 状态：已完成
- 交付：iclaude 评审和文案、两张官方界面截图、响应式双图、静态资源发布支持。
- 依赖：无
- 验收：示例清楚、截图安全、图片可读且能查看原图；既有三页操作保留。
- 验证：网站发布测试、构建、Playwright 六宽度/无 JS/图片完整加载与链接、冻结发行输入检查。

### T2 部署验收与归档

- 状态：待开始
- 交付：main/Pages 发布，当前 Specs 同步，Change 完整归档。
- 依赖：T1
- 验收：唯一 URL 与正式域名所有静态文件摘要/MIME一致，浏览器可显示两图，CI 通过。
- 验证：生产 Playwright、静态摘要、Change 校验、git 状态和 main CI。
