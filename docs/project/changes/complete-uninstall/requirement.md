# 一键完整卸载

> 状态：进行中
> 规模：大型
> 更新：2026-10-12

## 目标与范围

用户明确要求补上完整卸载并自动验收。新增一个命令删除当前安装的 Runweft 程序和选定数据根中的配置、数据库、连接凭据、缓存、日志与全部备份，并移除自身的全局 MCP/hook 和产品 Skill。其他软件配置、模型凭据、原生会话与用户源项目保留。

卸载只处理本机当前安装和 `--home` / RUNWEFT_HOME / 默认值选定的数据根；不扫描磁盘、其他账号或远端 Hub，不把全局 npm 缓存当作产品数据。数据根内受管任务工作区和成果属于删除范围；源项目及用户分支属于保留范围。npm 安装和可识别的平台包独立安装均支持，源码入口明确拒绝删除工程。

## 行为变化

### ADDED

- `installation/cli`：根级完整卸载，默认预览，明确执行后自动停止本数据根的 Hub、全部连接 Runner 和受管会话，移除自身接入与安装，删除数据且不生成持久备份。
- `installation/cli`：预检拒绝危险数据根、未知安装归属、运行中其他实例、无法确认的进程或受管 Git 元数据；失败非零并给出可操作提示，不声称完成。

### MODIFIED

- `installation/mcp`：既有 install/uninstall/restore 保持配置备份；完整卸载复用自身配置编辑规则，用内存快照回退，不新增磁盘备份。
- `installation/skill`：维护说明区分 npm 仅删除程序与 CLI 完整卸载；完整卸载只删除确认为 Runweft 的 Skill，保留其他 Skill。

## 验收标准

- [ ] 专用 npm prefix 安装的编译程序一条命令卸载后，程序入口、产品包、选定数据根及自身 MCP/hook/Skill 均不存在，无备份生成或保留。
- [ ] 预览无写入、无停止进程；危险路径、未知安装和配置错误在删除前被拒绝。
- [ ] 本机 Hub、多个连接 Runner/受管会话停止；其他数据根及独立 HAPI 保留，未知占用阻止删除。
- [ ] Codex/Claude 其他配置语义与 Codex 注释保留；模型凭据、原生会话、其他 Skill 和用户项目字节保持不变。
- [ ] 数据内符号链接不扩展删除范围；受管 Git 工作树注册按确切归属清理，源工作区和用户分支不变。
- [ ] 独立平台包、重复卸载、损坏产品数据与 npm 删除失败均有真实或定向测试；基础类型、根测试、构建通过。
