## T4 账号管理与恢复

CLI 提供账号查看/改名、登录环境列表及撤销、改密码和全端退出；密码类操作要求人工隐藏输入，非交互立即返回明确错误，不等待不可见输入。部署者命令只打开已有本机数据库，将重置码写入显式新文件（0600），缺失数据库时不创建。用户恢复命令隐藏输入重置码与新密码，与 Web 共用账户领域。

隔离 PTY 以合成账号走完注册、改密码、再次登录和重置密码，确认输出无秘密且身份 UUID 不变；部署者输出文件/权限和缺失数据库拒绝通过。联合验证首轮实际为 17 pass、1 fail：非交互命令先向 stderr 打印 Hub 提示，随后 JSON 错误无法解析。主 Agent 在读取失败结果后仍提前提交了 T4 通过记录，这是记录错误；不改写已推送历史，追加 T9 修复并复验。账户存储测试另覆盖重置码替换、单次消费和所有既有 CLI/browser 凭据撤销。
