# 账号密码与 CLI 核心能力实施计划

落实 [需求](requirement.md) 与 [技术方案](technical.md)，按可验证的用户场景交付。用户已确认方案并授权拆分计划后开始实现；不再调用 iclaude，后续独立代码评审使用隔离上下文的 Codex Agent。实现位于独立 Change 分支和 worktree；主工作区保留 develop。

T1 与不涉及界面的 T2 可分开推进；T1 发布预览后可先提交检查点再推进 T2。原型必须经用户验收才能实现对应 Web 页面，未答复不视为通过；该等待不阻塞后端/CLI。其他任务串行集成，避免共享身份、连接及任务契约并发修改。

## T1 交付账号与首次接入交互原型

在现有原型包新增独立入口，使用内存演示覆盖注册并连接、已有账号登录、多空间、过期请求、密码恢复、环境撤销和首次空态，保留其他 Change 的入口。提供固定预览并验收桌面/窄屏和关键交互；原型由用户明确验收后才开始对应页面实现。

验证：原型构建、Playwright 操作和各声明视口、发布引用校验。它只证明交互，不证明账户或执行链路。

## T2 交付账户、独立凭据与稳定后台身份

建立用户名/密码与 Identity 的一对一关系，注册自动创建默认空间；实现密码校验、独立 browser/CLI 凭据的认证/期限/单项撤销和账户 API。将 JWT ref 改为凭据引用，后台 serviceUser 同时改为稳定 owner/space 内部主体。采用新的唯一数据库格式，旧格式拒绝并保全，不提供迁移。

验收：同一用户名不重复建身份；退出后同账号回到原身份/空间；原始用户凭据与派生 JWT 的入口边界有效；退出不停止已接受任务，成员/资源撤权仍按现有机制处理。实现期间可保存尚未接通产品入口的 doing 检查点，不把库级测试冒充完整登录交付。

验证：账户领域及 hub-access 定向测试、typecheck、core；用隔离数据目录核对数据库格式拒绝及后台任务身份。改动影响的集成组按 ci-scope 执行。

## T3 交付确认即激活与人工 CLI 登录

以客户端最终秘密及摘要替换 RSA 交接，保留本地待连接记录；实现 begin/confirm/complete/cancel、有限等待和幂等恢复，删除 ACK/consumed。实现人工终端注册/登录、退出和状态，密码通过隐藏输入，非交互给出 Web 入口；认证后选择本地默认空间，不重复输入密码。移除身份 token 的 argv/env/文件导入契约。

验收：确认事务只创建一个 CLI 凭据；丢响应或保存失败用原请求续接；确认前后取消及期限语义正确，不覆盖更新的连接；机器归属冲突保留原连接。CLI/Web 凭据分离，正常输出无秘密。

验证：cli-connect、账户 CLI 的隔离 TTY 场景、0600/格式拒绝/失败恢复；相关工具、构建及集成检查。

## T4 交付账号管理与部署者协助恢复

实现 CLI 账号显示名、登录环境查询/撤销、改密码、全端退出、恢复；部署者本机命令签发短期一次性重置码到显式受限文件。改密码、重置和全端退出事务撤销全部用户凭据，包含确认后本地未保存的 CLI；不混淆机器凭据。

验收：CLI/Web 共用领域规则；修改密码/全端退出需当前密码；重置码期限、替换和单次消费有效，无数据库时拒绝本机管理操作。原生短 JWT 不能进入账户管理。

验证：账户 API、CLI TTY、并发消费及凭据撤销测试；访问网关的流连接定向回归。

## T5 交付空间协作 CLI

补齐空间 list/show/create/rename/permissions/use/leave、成员管理、邀请创建/列表/撤销/接受。邀请通过受限文件交付；所有角色与最后 owner 约束复用 HubStore。默认空间失效时仍可 list/use；创建/加入不自动切换，不迁移既有任务或 MCP 上下文。

验收：Agent 无需网页抄 UUID 即可完成空间协作；CLI 与已有领域 API 相互可见；越权拒绝；本地默认与单次 --space、浏览器选择分别生效。

验证：CLI 空间管理闭环、Hub 成员/邀请测试和运行中上下文不漂移断言。

## T6 交付无需机器的任务查询与诊断

分离用户空间只读 client，接通 list/show/wait/result show/artifacts show；任务列表共享筛选、排序、分页，并在分页前保留默认 machineId+cwd，显式 --all 扩展查询。保留 HAPI_SESSION_ID 的受管子任务拒绝判断。新增有界 task messages，沿用原生消息游标与网关，不恢复或重发执行。

验收：仅登录终端无需登记机器/Runner 即可查本人任务；MCP/控制范围不扩大；等待超时不停止执行；原生消息注明跨轮共用 session，缺失或撤权给出事实。

验证：hub-delegation/console-tasks 及命令级只读查询测试；分页前过滤、权限、子任务限制、无 session、等待取消和原生消息分页。

## T7 交付 Web 账户流程与任务定位

按已验收原型实现登录/注册与一页连接确认、成功态、账户设置/恢复/环境撤销。保持标签页会话和受限原生页隔离。新增 task open/--print，并将 show 链接落在可恢复登录定位的 Hub 任务/轮次详情；用户点击原生入口才打开原生页。

验收：默认一次表单，无 token 备份；新标签按实际会话条件登录；页面仅声明已授权，本机完成由 CLI 报告。深链登录后定位正确，URL 无秘密，角色/任务归属未放宽。

验证：web-identity/web-connect、Playwright 表单/密码管理器字段/键盘/窄屏/状态、原生新标签及撤权测试。

## T8 交付 Agent 首次体验并完成整体验证

更新 Runweft Kit、官网及使用说明，使 Agent 复用连接与资源、自动匹配/绑定当前仓库，创建/复用私有评审 Agent，通过 CLI spawn/wait/show 先读回报告；MCP 重载及实际调用单独报告。同步命令和数据格式说明，完成需求到证据映射。

验收：满足前置条件时，一次用户接入请求、一张账号/连接表单、零条人工 CLI、无需第二段体验提示；不猜测歧义、不冒领 CLI/MCP 父上下文。只读 CLI、真实执行与 MCP 各有独立证据。

验证：Kit 结构检查与独立 Agent 场景，测试手册选择的隔离 CLI/浏览器/已授权真实模型验收，最终 typecheck/test/build/test:tools/文档及流程检查。全量差异由 Codex Agent 独立评审；未实施的人工验收不记通过。当前另一个 Change 的既有集中流程错误单独记录，不据此改动其文件。
