# 1.1.1 npm 正式补丁发布

> 状态：进行中
> 规模：中型
> 更新：2026-10-02

## 目标与授权

用户要求“追加版本试一下”，在已合入 main 的产品上发布下一个补丁版本 1.1.1，真实验证 npm 可信上传并同步正式官网。用户授权工程决策、逐任务提交、推送、发布和自动验收；不重复设置人工门禁。

## 行为变化

### MODIFIED

- `release/distribution`：当前五包 latest 为 1.1.0，可信发布仅验证过预演；目标以既有稳定 tag 流程发布同版本五包 1.1.1，公开包与冻结候选完整性一致。
- `installation/cli`、`installation/skill`：目标提供可匿名安装的 1.1.1，携带当前 npm 接入 Skill 和配套使用说明。
- `website/product`：目标正式官网的安装命令、Agent 对话与参考页统一为已公开的 1.1.1。

## 验收标准

- [ ] 匹配版本的 v1.1.1 tag 触发真实四平台构建/安装和五包 OIDC 上传；保存原候选及回执。
- [ ] 五包公开版本/latest、精确平台依赖、下载 SHA-512 与候选一致；匿名 Linux x64 专用 npm 安装、版本、Skill 和配套 HAPI 校验通过。
- [ ] main 已推送版本提交；Pages 生产部署和正式域名三页/资源、npm 1.1.1 命令通过自动校验。
- [ ] 当前文档/Specs 更新，历史 1.1.0 包、离线候选、归档和用户配置保持可追溯。

## 已确认依据与边界

五包公共 latest=1.1.0、1.1.1 均返回 404；远端没有 v1.1.1。main 的四平台安装与五包 OIDC 预演、官网生产已通过。沿用现有 npm/Pages 工作流，不改 HAPI、runtime、权限或发布规则。新候选不继承旧版本的模型/物理跨机验收，本轮验证发布、安装与官网；不生成新的离线整包。
