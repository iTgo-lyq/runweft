# HAPI 默认简体中文

> 状态：进行中
> 规模：小型
> 更新：2026-09-30

## 需求

HAPI 网页在浏览器尚未保存有效语言选择时默认使用简体中文；已有英文或中文选择继续生效。用户已要求修改默认值，并授权工程决策、本地自动验收及逐任务提交。

## 行为变化

### MODIFIED

- `dashboard/subagents` — 原生 HAPI 界面语言：当前未保存有效语言时使用英文；目标使用简体中文，仍可在设置 → 通用 → 语言选择 English。
