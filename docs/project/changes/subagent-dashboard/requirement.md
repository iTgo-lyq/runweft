## 独立验收与交付边界

仅使用已验收的本地共享任务即可验证全局列表、筛选、状态及 HAPI 详情跳转；不需要远端功能先实现。消费委派统一查询，不读取或修改领域内部表，不在页面重建状态机。

Git/附件交付状态由各提供方进入同一查询契约。没有声明代码交付的任务显示不适用，不能显示为已交付；已启用能力的未知状态必须保留未知。远端及完整成果组合在对应能力就绪后验收，并纳入最终集成矩阵。

## 行为变化

### ADDED

#### `dashboard/subagents`：跨工作区查看当前协作

展示当前用户已有访问范围内的 subagent 总览，不限某一个父会话。最少包含父工作区/任务、agent、机器与 runtime、工作目录模式、本轮执行状态、执行进程是否已结束、成果交付状态、最近更新时间及摘要。

可按工作区、父任务和状态筛选；详细对话、审批和机器管理尽量链接或复用 HAPI 已有页面。看板汇总父子关系，不重复开发 HAPI 对话控制台、原生日志或机器管理。

本 Change 提供只读总览，不承载 agent 编辑、skill/MCP 管理、合并冲突或正式工作台布局。运行与交付状态分别表达；进程已结束但 session 可续接不标成异常。HAPI 离线时显示信息过期，不推断任务成功。

## 验收标准

- [ ] 可从同一页面看到多个工作区/父任务下的 subagent，并定位 HAPI 详情。
- [ ] 状态源自 HAPI 和委派关联；未知、运行结束与交付失败不会混同。
- [ ] 不额外建立权限/账号系统，不重复实现完整 HAPI UI。
- [ ] 主宿主已退出不影响查看已有记录，但看板不承担恢复主会话。

- [ ] CLI 默认打开 Runweft 看板，可显式打开 HAPI；使用同一地址/登录，安装后不依赖源码或外部 CDN。
- [ ] 工作区/父会话/执行状态筛选及分页可用，提供空数据、无匹配、认证失效和离线提示；失败刷新保留旧记录并明确陈旧。
- [ ] 任务输入、定义 instructions 与凭据不进入列表；报告纯文本有界显示，用户内容不能执行 HTML；共享任务代码显示不适用，停止的可续接 session 不算异常。
- [ ] 本地和 Hub 模式都可只读查看，不要求浏览器所在机器运行 Runner；响应按既有 namespace 隔离。
