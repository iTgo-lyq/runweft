# 全局 Subagent 看板实施计划

> 来源：[Requirement](requirement.md)
> 技术方案：[Technical](technical.md)
> 状态：已完成
> 执行模式：主 agent 逐任务本地提交；本 Change 唯一一次 iclaude 评审已完成并由主 agent 复核，见 [Execution](execution.md)。

## 交付目标

安装同一 Runweft 包即可查看当前 namespace 下跨工作区、跨主会话的协作状态，并沿 HAPI 访问详细会话。只做全局只读可观察性，保持机器/runtime/agent 分开及原生能力优先。

### T1 无需本机 Runner 的全局只读查询

- 状态：已完成
- 依赖：已验收任务查询、资源库存与 namespace 认证。
- 交付：任务领域总览投影、筛选/分页、必要父子与 session 关联；公开只读 API，复用 overview 状态和现有资源名称；HAPI 库存不可用时保留业务事实及查询错误，离线/未知执行端的活跃行显示可能过期。
- 验收：多工作区/父会话与 namespace 隔离，执行/stop/代码/附件分开，unknown 与未启动准确，无真实 session 不造链接；查询不写业务状态或调用模型/原生探测，返回有界内容。
- 验证：真实 SQLite+HTTP 聚焦，陈旧、认证与输入校验，类型检查、相关任务查询回归及千任务读取耗时检查。

### T2 编译内置页面与统一打开入口

- 状态：已完成
- 依赖：T1。
- 交付：嵌入 HTML/CSS/JS、同源 HAPI 登录、自动/手动刷新、筛选/分页、任务状态轨与详情；open 默认看板并检查 Hub 能力、--hapi 原生入口，使用说明同步。
- 验收：不依赖源码/CDN，无新账号/部署；同源登录写回与 JWT 过期单次重新认证、空/错/过期状态、纯文本渲染、并发刷新次序、键盘和移动布局；本地/Hub 登录指向当前连接，日志和链接不泄漏凭据。
- 验证：编译独立运行的静态资源/API、前端逻辑及网关路径聚焦，根 types/全量与现有服务 smoke。

### T3 真实记录、浏览器与候选包整体验收

- 状态：已完成
- 验收环境：2026-09-30 用户明确允许 Playwright，无需连接用户真实浏览器；候选编译、安装与真实历史记录查询已通过，继续 Chromium 交互与布局验收。
- 依赖：T2。
- 交付：使用 C10 已结束任务和专用状态 fixture 的完整看板验收；四平台候选更新、npm 实装与用户说明。依用户授权自动本地验收，Specs/归档单独提交。
- 验收：安装后跨主会话/工作区显示、筛选、HAPI 会话跳转、离线/恢复、认证失效、无匹配与窄屏；既有本地/远端事实一致，不重跑已结束模型。真实浏览器证据与 HTTP/DOM/源码检查分开。
- 验证：Playwright Chromium 自动驱动与证据回传，实际 Hub/CLI/安装查询，四平台编译；每项需求映射及已知限制。HAPI 无改动时复用此前检查，不重复完整上游测试。

## 约束

不新增调度/审批/清理写入口，不读取任务领域内部表实现页面，不改原生 adapter 或 HAPI UI，不扩展到正式工作台。真实浏览器可用性先实测，失败不冒称验收，不把未完成核心行为交给最终发行 Change。
