# 清理无用的 `.dev-smoke` 历史产物

## 背景与目标

用户明确要求将本 Change 收敛为无用历史产物清理，随后提交、归档并合码。该范围沿用前期已经授权并执行的 35 项清理，以及删除 AGENTS 中指定临时文件放 `.dev-smoke/` 的提示。

本次为 small：只包含一次性本地清理、工程提示删除和清理证据，不修改产品代码、测试逻辑、证据协议或共享契约。原未执行的测试与脚本改造计划退出本 Change，后续以独立任务评估；旧草案保留在 Git 历史中。

## 范围与方案要点

按人工核实的明确清单删除历史安装、缓存、验收输出、日志和生成快照；不按通配规则扫描未知现场，不跟随符号链接。删除清单、消费者核对与执行结果见 [Research](research.md)。

保留三个未满足删除条件的条目：安装检查脚本在必要能力迁入正式入口前保留；索引纠错草稿未确认已有正式事项前保留；来源未知的 deploy-key 元数据保持原样，不读取内容或提交源码。

不移除仍被正式入口使用的目录约定，不改历史归档，不迁移原生恢复数据，不修改 HAPI、模型配置和凭据。此次清理授权不成为产品自动清理策略。

## 行为变化

- REMOVED：本机已确认不再被消费的 35 项历史产物。
- REMOVED：AGENTS 中“临时文件放 `.dev-smoke/`，不提交”的提示；原搜索排除规则保留。
- 产品、测试和发布行为无变化。

## 验收标准

1. 35 项清单路径全部不存在，删除仅限核实范围且不跟随外部符号链接。
2. 三项保留内容未修改，当前 `.dev-smoke` 只剩这三个顶层条目。
3. AGENTS 不再指定 `.dev-smoke` 为临时文件位置。
4. 最终相对 main 的差异仅包括 AGENTS 提示及本 Change 清理记录；测试/辅助脚本重构不混入。
5. 文档、工作流及 diff 校验通过，关闭状态真实记录验收、Specs 判断和归档结果。
