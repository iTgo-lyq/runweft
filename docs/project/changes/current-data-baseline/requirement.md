## 需求

用户确认工具尚未在其他机器部署，数据库及本地配置以当前工作区结构作为首次部署和后续升级讨论的基线；授权清理当前机器全部 Runweft 历史测试环境。此前公开包使用的测试格式不构成此次发行的迁移前提。

## 行为变化

产品代码行为无变化。部署基线为 Hub schema19、client schema1、config schemaVersion1及当前连接文件/Task/Round结构；既有只支持当前格式的行为继续有效。本次删除测试数据是用户显式授权的开发维护操作，不新增产品清理或迁移入口。

## 范围

- 当前及历史 Runweft 仓库的 `.dev-smoke/`、已确认属于 Runweft 的 `/tmp` 测试目录，以及本机旧测试部署 `~/.runweft`。
- 删除前停止使用上述目录的精确进程，删除测试库、配置副本、附件、工作区、缓存与测试证据现场。
- 保留两仓库源码/Git、已归档验收说明和脱敏摘要、正式 `dist` 交付及现有安装程序；保留用户原生 Codex/Claude 配置、凭据、历史与其他项目/HAPI服务。
