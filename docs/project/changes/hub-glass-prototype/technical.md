# 原型技术方案

独立原型使用原生 DOM、模块化 JavaScript 和 CSS，自包含 IIFE 构建。重设计应用壳、页面渲染和虚构数据，不引入 React、Next.js、Tailwind 或外部字体。hash 表示当前页面，筛选、选择、弹窗和编辑均用内存状态。

玻璃效果仅用于侧栏、空间切换、分段控件和浮层：半透明底、轻微渐变、边缘高光与 backdrop-filter；缺少滤镜支持时使用实底回退。阅读区使用高对比文字、语义状态和实底表格。详情面板以报告与下一步操作为主，元信息和高级字段按需展开。

保留现有八个入口、虚构数据与无请求契约、opaque iframe、bridge ready/error 握手。用户输入通过 textContent 或转义后插入；表单在 iframe 内阻止原生提交。键盘支持原生 button、dialog、select 和 input，弹层关闭恢复焦点，图标控件具备名称。

浏览器覆盖 1440×900、834×1112 和 390×844；检查八入口、导航、搜索/筛选、详情/轮次、资源编辑、邀请、空间切换、空态、离线、错误恢复。检查无外部资源/接口、无存储访问、无控制台错误与溢出。截图逐一检查后交付。
