# Hub 前端重构技术方案草案

## 基线与接入路线

产品目前使用 HTML、TypeScript 原生 DOM 与 CSS，经 Bun 内嵌静态资源和浏览器脚本；API 调用、权限上下文和错误恢复已在现有客户端中实现。独立原型使用虚构数据与内存状态，两者是不同验证对象。

建议沿用产品当前栈，将设计系统、应用壳与场景视图分开，复用现有请求/授权与恢复语义。暂不以视觉重构为由引入 React/Next.js/Tailwind、外部字体、CDN 或新的前端 API 层。shadcnuikit 的布局与组件模式可辅助选型，其 React 源码不能当作已安装的产品组件；需要框架迁移时另行说明证据、打包影响和取舍，再作技术确认。

[原型设计规范](../../../../packages/prototype/DESIGN.md)提供蓝色 token、局部玻璃、响应式和基础交互依据。产品样式使用同源 CSS、语义类与状态属性，符合现有 `style-src 'self'`，不放宽 CSP 来容纳内联样式或外部资源。新增共享浏览器模块必须同时进入内嵌资源映射和编译产物；保留已知资源路径及未知路径 404。

## 状态与行为边界

共享 UI 负责布局、控件、焦点、反馈与渐进展开；业务操作继续消费服务端 permissions 和既有请求封装。身份/空间上下文变化使旧请求失效，刷新保留同上下文的成功快照；使用渲染代次或等价失效机制阻止迟到响应覆盖当前界面。

连接确认 URL 的 `#connect=<请求 UUID>` 优先级必须保留。页面导航若引入 hash 或内部路由，不得吞掉确认请求、泄露凭据或自动批准连接；未登录、待确认与正常工作台分别验证。

表单沿用原生校验和明确字段错误；提交防重复与请求 ID/摘要/回执核对保持分离。弹窗/抽屉开关不能丢弃未知写入的恢复信息。用户内容用安全文本节点呈现；报告不作为可信 HTML 执行。产品继续使用既有身份 sessionStorage 格式，原型保持无持久存储，不引入数据迁移或新配置格式。

| 场景 | 产品落地约束 |
| --- | --- |
| 任务检索与统计 | 服务端 overview 只接受既有 workspace/parent/status/page/limit，不发送虚构的全文检索参数。文本检索若实现为本页过滤，明确文案、总数与分页区别。没有聚合接口时不承诺精确全量状态计数。 |
| 任务详情 | 轮次、报告 offset 和折叠状态与任务 ID 绑定；详情刷新保留阅读位置。文件/代码与停止状态来自真实事实，结果未知不转为成功或可重发。 |
| 原生入口 | 复用现有 openNative 与独立标签页短 JWT 深链接；审批、会话及文件仍由 HAPI 内置 UI 提供。不得复制演示审批弹窗替代真实授权或添加任意终端。 |
| 资源与选择 | 保留私有内容、可管理/可使用/可分享/可治理差异；登记和空间停用独立。选择项失效后展示原值和原因，解析预览使用既有端点。 |
| 身份与成员 | 备份和轮换有显式用户动作；未知轮换结果核对新 token。角色及最后所有者约束来自真实响应，原型示例邮箱不成为产品账号字段。 |

## 渐进交付与验证

先建立共享壳与控件，再按身份/空间、任务、资源、Agent、仓库/选择、成员逐段替换。每段实现连同真实接口和错误路径验证，不引入同时维护两套生产页面的长期兼容层；现有原型固定版本保留，行为或设计明显补齐时发布新的固定预览。

每个任务同时覆盖产品与原型差异。产品 Playwright 使用专用数据目录和凭据，验证权限、恢复和真实响应；原型检查 opaque iframe、自包含、ready 握手和无持久存储/外部请求。共享截图尺寸为 1440×1000、834×1112、390×844。最终按 ci-scope 选择类型、核心、构建、工具和集成检查；真实模型验收只有在已有明确授权时执行。

本轮为范围升级后的草案。当前数据结构、执行协议和后端契约保持既有规格，因此不新增迁移框架或 HAPI 改造；若实现调查发现实质缺口，记录证据并返工至相应阶段。
