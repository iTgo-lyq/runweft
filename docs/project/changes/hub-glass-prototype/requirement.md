# 蓝色轻玻璃 Hub 交互原型

用户希望基于现有资源输出一版现代、易读、易操作、冗余少且精致的后台原型。保持蓝色主题，允许调整明暗与渐变；仅部分组件使用苹果液态玻璃风格，避免堆砌。用户授权自由完成设计，本次只交付原型。

## 范围与完成条件

重设计现有八个入口：身份与空间、任务、机器、Runtime、Agent、仓库、个人选择、成员。工作台通过固定导航、空间切换和页面工具栏组织信息；重点完成任务检索、状态筛选、任务详情与报告、资源查看与编辑，以及成员邀请等代表性交互。低频信息渐进展开，避免反复显示 ID、内部协议与大段配置。

导航、空间切换器和弹层采用克制的蓝色轻玻璃效果；正文表格保持清晰实底。提供手机、平板、桌面布局和键盘访问，尊重减少动态效果偏好。

所有内容均为虚构数据，状态仅保存在内存中，无持久化、真实接口或凭据。保持现有八个稳定入口与受限 iframe 的 ready 协议。构建自包含 HTML，Playwright 验证全部声明设备、关键操作、空态、离线、错误场景、网络隔离与无横向溢出，并交付可打开预览及截图。

## 方案与依据

复用独立原型包，不改产品 Hub、HAPI 或根工程依赖。现有原型来自 Hub `23ca1d4`；本次 UI 是设计探索，不能作为产品功能验收证据。用户已明确要求重新设计，新的视觉决定记录到包内 DESIGN.md。

使用 frontend-design 形成统一视觉系统，shadcn 的交互与语义规范辅助检查。已通过 shadcnuikit MCP 查询 project-list、data-table2、empty-state3：其 Next.js/React/Tailwind 源码无法直接安装到当前原生 DOM 原型；本次参考列表层级、筛选和渐进披露模式，以本包原生实现适配，不声称直接复用了 React 组件。

现有自建 R2 托管与不可变版本策略保持，完成后生成新的固定预览；原版本继续保留。对应产品实现等待原型评审，不属于本次交付。
