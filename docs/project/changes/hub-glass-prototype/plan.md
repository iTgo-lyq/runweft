# Hub 前端交互与样式重构计划草案

沿用本 Change 的 ID、分支、原型与 R2 固定版本。执行默认按任务编号串行；各任务同时包含必要实现、原型补齐、失败路径验证与文档证据，不按单纯编码/测试分层拆任务。大型重构进入产品实施前，先完成新版需求、技术方案和计划确认，以及用户对相关原型的验收。

## T1 完成蓝色轻玻璃八入口原型与交互验证

已交付的独立内存原型、固定 Git 快照、R2 版本和浏览器证据继续保留。其证据仅覆盖原型，不能替代以下产品任务的接口、权限、恢复与整体验收。

## T2 交付统一应用壳与基础交互组件

建立蓝色 token、受控玻璃、响应式导航、空间切换容器和公共按钮/表单/弹窗/抽屉/反馈。接入产品内嵌资源与 CSP，完成登录前后布局和真实上下文失效边界。验证三尺寸、键盘/触摸/焦点、导航与未知资源 404；保留连接确认 URL 的进入路径。

## T3 重构真实身份与空间接入流程

落地领取/导入、名称、备份/轮换、创建/切换空间和加密 CLI 连接确认。验证未知创建/轮换结果、401、断网、跨 origin 拒绝、空间切换和迟到响应隔离；核对凭据不泄露到 URL、DOM 属性、日志或其他站点。

## T4 重构任务列表与轮次交付详情

落地真实筛选/分页、准确统计、抽屉详情、报告分页/位置、状态与附件/代码表达、原生会话/审批/文件入口及 Agent 维护说明。验证查询参数范围、离线/未知/停止事实、刷新恢复、阅读状态保留和短 JWT 到期；不引入假审批或自动重发。

## T5 重构机器与 Runtime 资源管理

落地资源卡片/列表、状态与权限、登记/空间关联/分享/治理、检查及接入指引。验证所有者、普通成员和管理员的可见/可用/可改边界，机器离线、凭据撤销、空间停用和共享前置条件；不在浏览器执行本机登记或凭据轮换。

## T6 重构 Agent 定义与分享管理

落地完整定义、版本条件编辑、历史、分享范围与治理。验证私有定义隔离、权限变化、并发版本冲突、请求结果未知和登记恢复；精简默认展示但保留全部已有字段和危险操作确认。

## T7 重构仓库与个人协作选择

落地仓库名称/别名/登记、只读 checkout、空间/仓库级选择、runtime override 与真实解析预览。验证创建回执、别名移除、失效选择保留、清除层级和解析失败；不自动改 Git remote、重建仓库或切换原生配置。

## T8 重构成员与邀请协作流程

落地角色管理、邀请生成/撤销/接受、成员移除与退出。验证最后所有者保护、权限变化、失效邀请和当前空间隔离，完成真实角色场景的三尺寸截图与操作记录。

## 整体交付

所有场景任务完成后，检查完整能力与验收项对应，按实际改动运行 ci-scope 所需检查及聚焦 Web 集成；使用真实接口测试数据复演全部入口，保留同场景截图与原型差异说明。large 关闭前由与实现上下文隔离的 Agent 或用户进行独立评审，问题写入 Review 并定向修复/复验。用户验收产品效果后，再同步受影响 Specs、归档、合入协作分支。产品正式发布不由本计划自动授权。
