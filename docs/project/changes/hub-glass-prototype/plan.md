# Hub 前端重构计划

依据[需求](requirement.md)与[技术方案](technical.md)。T1（原型）已完成；T2–T8 为回滚前的旧计划，编号不再使用。以下任务按编号串行执行。

整体验证：每个任务完成时运行与改动相称的类型检查、单元测试、前端构建和对应的浏览器测试；全部完成后按 ci-scope 跑完整检查，做上下文隔离的独立评审，再请用户验收产品效果。浏览器测试在本机设置 `CI=true` 关闭 Chromium 进程沙箱（与原型包一致）。新界面替换旧页面后，旧的页面测试在对应任务中删除并由新测试取代；在全部任务完成前，Change 分支上的 Hub 可能暂时缺少尚未迁移的入口。

## T1 完成蓝色轻玻璃八入口原型与交互验证

- **交付**：原型阶段的 8 个入口原型，已于 2026-10-19 经用户验收，记录见 [执行记录](execution.md)。

## T9 UI 库基础与前端构建链

- **交付**：`packages/ui` 建立 token（浅色、深色、手机纯黑、两种玻璃、减少透明度与动态效果）及其 Tailwind 4 主题映射；自有图标组件；shadcn 方式的基础组件（按钮、徽标、输入、多行输入、下拉、开关、分段、标签页、下拉菜单、弹出层、对话框、确认框、侧边抽屉、轻提示）和工作台壳（侧栏、玻璃工具栏、手机抽屉）；共用的前端构建函数（TSX 打包加 Tailwind 生成 CSS）；组件目录页；DESIGN.md 移入 UI 库并更新原型配置的引用；README 写使用与扩展约定。根目录加入精确固定的依赖与 `jsx` 配置。
- **验收**：组件目录在浅色与深色下展示全部组件及其状态；键盘操作、可见焦点、Escape 关闭浮层并恢复焦点、减少动态效果与减少透明度检查通过；在调整后的 Hub CSP 下无违规；类型检查通过。
- **验证**：组件目录的 Playwright 检查与 GPU 合成截图人工查看；`bun run typecheck`。

## T10 Hub 前端骨架、账号与连接

- **交付**：`src/hub/web` 的入口、工作台壳、hash 路由（保留 `connect`、`space`、`task`、`round`、`native-expired`，新增 `view`）、会话与空间上下文、`HubApi` 浏览器实现（超时、错误映射、空间 JWT 缓存、创建回执、原生会话打开）；构建时打包前端并嵌入二进制，`bun run dev`、`scripts/build.ts` 与集成测试的编译路径都包含这一步；`page.ts` 提供新资源，CSP 只把 `style-src` 改为允许内联。账号注册、登录、重置密码，连接确认与已授权结果，账号设置（登录环境与断开、改密码、全端退出），侧栏的身份改名、空间切换、创建空间、接受邀请，以及“接入新环境”说明。
- **验收**：账号与连接相关的现有能力全部可用；HTTPS 要求、会话失效回到登录、身份或空间切换后旧响应不生效、凭据不出现在 URL 与页面文本中；三档尺寸无横向溢出，浏览器无错误与 CSP 违规。
- **验证**：新的账号与连接 Playwright 测试取代 `web-identity`、`web-connect` 中的页面部分；`bun test` 覆盖 hash 路由与上下文隔离；类型检查与构建。

## T11 任务

- **交付**：任务列表（状态分段、工作区与主宿主筛选、每页数量、分页、本页查找、离线库存提示）与检查器（轮次纬线、分段阅读报告、交付与文件和代码状态、诊断原始数据、原生详情与文件入口、交给 Agent 继续处理的说明）；`#space=…&task=…&round=…` 深链接打开对应任务与轮次。
- **验收**：现有任务能力全部可达；执行未确认不表达为可重发；刷新失败保留已读内容与当前轮次；原生会话打开流程与限时凭据边界不变。
- **验证**：新的任务 Playwright 测试取代 `console-tasks`、`console-history`、`web-task-links` 的页面部分。

## T12 机器与 Runtime

- **交付**：机器与 Runtime 的列表和检查器：改名、登记与取消、凭据状态与撤销、探测原生工具、空间关联与共享开关、Runtime 登记与检查、空间治理；按权限显示操作。
- **验收**：现有资源能力全部可达；会撤回权限或影响执行的操作先确认；非本人资源只显示允许的概要。
- **验证**：新的资源 Playwright 测试取代 `console.ts` 中对应部分。

## T13 Agent、仓库与我的选择

- **交付**：Agent 定义列表与检查器（创建、编辑生成新版本、登记、分享范围与成员、版本历史、空间治理，他人私有定义只显示治理概要）；仓库（登记含别名、改名、别名增删、登记状态、本人 checkout 只读）；我的选择（空间与仓库默认、Runtime override、清除、解析预览，失效项保留原 ID 与原因）。创建使用请求 ID 与回执核对。
- **验收**：现有能力全部可达；创建结果未知时不重复创建，可按原请求核对；选择失效不自动回退。
- **验证**：新的 Playwright 测试取代 `console.ts` 中对应部分，并覆盖创建回执恢复；`bun test` 覆盖回执状态。

## T14 成员与空间

- **交付**：成员列表与角色调整、移除成员、生成邀请（只显示一次，可复制，不提供下载）、撤销邀请、空间改名、退出空间与最后一位所有者的提示。
- **验收**：权限差异与最后一位所有者限制正确；邀请 token 只在生成时出现。
- **验证**：新的成员 Playwright 测试取代 `web-invitations` 与 `console.ts` 中的成员部分。

## T15 原型包改用 UI 库

- **交付**：原型包用 React 与 UI 库重写 8 个入口、内存数据和演示控制，仍构建为自包含 HTML；`verify.mjs` 随之更新；从干净提交发布到 R2 并登记到原型清单和本 Change。
- **验收**：8 个入口在三档尺寸、浅色与深色下与已验收版本的同场景截图对照，没有非预期差异；原型包中不再保存组件样式或交互代码的副本。
- **验证**：`CI=true node verify.mjs`、发布脚本测试，以及逐入口截图对比。

## T16 收尾

- **交付**：删除旧前端模块、旧样式与剩余的旧页面测试；更新 `ci-scope.mjs`，让 `src/hub/web`、`packages/ui` 的改动触发类型检查与对应测试；更新 README、测试手册等受影响文档。
- **验收**：仓库中不再保留旧前端代码；按 AGENTS 的检查全部通过。
- **验证**：`bun run typecheck`、`bun run test`、`bun run build`、`bun run test:tools`、`node scripts/check-docs.mjs`、`node scripts/check-workflow.mjs`、`git diff --check`，以及全部新页面测试与受影响的集成测试。

## T17 修复独立评审问题并完成 CI 验证

- **交付**：完成整个产品差异的独立评审，修复发现的问题；定位并修复 macOS ARM64 安装验收的进程核对失败，保留未知进程时拒绝卸载的边界。
- **验收**：评审问题有复现、修复与复验记录；最终提交的必需 CI 检查通过。用户已明确授权完成收尾并合入 develop，验证通过后记录验收、同步 Specs、归档并集成。
- **验证**：确定性的竞态回归、受影响的浏览器与卸载测试、完整工程检查及四平台安装 CI。
