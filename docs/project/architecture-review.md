## 优先验证

1. **身份与角色：** 在专用配置中验证 Codex/Claude 的首次 initialize、tools/list、tools/call，覆盖 HAPI 受控子会话、原生子会话、同 cwd 多会话和停止后 resume；记录实际版本及白名单身份字段，不记录完整环境或凭据。
2. **执行与工作区边界：** 核对已存在机器处理器从 Runweft 的可达入口；验证无活跃 agent 会话时的准备/收尾调用、固定基线及停止证据。原型不替代两种 runtime 的真实执行、停止和续接验收。
3. **会话外交付：** 验证执行机通过既有认证取得输入、提交输出，覆盖准备前无会话和停止后无会话；区分对象传输成功与 Git 语义完整性。单机协议试验不算真实远端验证。

以上调查最迟在委派生命周期 Technical 定稿前确认承载位置与调用顺序；具体公共 Git 实现和对象服务仍分别在工作区与附件 Change 交付。
