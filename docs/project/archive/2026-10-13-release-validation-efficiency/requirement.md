## 背景与目标

1.1.5 正式发布总计 35:42，其中一次官网故障处理 5:35；相同传播条件下正常链路约 30:07。审计已确认共享关闭计时器在成功后仍保持进程存活、service-package 对同一平台程序重复执行一套服务验收。用户确认先消除这些开销，再根据实测拆分并行，独立 worktree 开发，与 iclaude 复核后合入 main 并正式发布测量。

## 范围与行为

MODIFIED：成功的验收及时退出；失败仍有超时、强制终止与非零状态。删除直接运行原始平台目录的重复服务验收，保留独立 tarball/symlink 和 npm launcher 两条完整路径。按实测配置有限并行和独立 CI 分片，候选身份及全部必需门禁保持严格。

优化上传前磁盘准备的实测开销；保留可用空间检查和不足时清理。保留真实心跳过期、大文件、103 文件跨批、完整卸载、四平台和网页验收，不提前上传主包，不复用不同候选或历史验收结果，不引入 Actions artifacts。

## 验收标准

- 同一 1.1.5 候选、同一环境有修改前后的脚本计时，测量失败明确记录，不推断成功。
- 成功、失败和超时清理有回归验证；拆分后每个既有有效用例恰好覆盖，任何缺失、失败、取消或非预期跳过阻止晋级。
- iclaude 独立复核全部差异和验证证据；问题修复并定向复验后合入 main。
- 对新版本实际完成 npm 发布、公共验收、晋级和官网，报告耗时分布与传播/执行/排队的边界。
