# 轻量 Agent 定义实施计划

> 来源：[Requirement](requirement.md)
> 技术方案：[Technical](technical.md)
> 状态：已完成
> 执行模式：逐任务提交
> 评审方式：当前工作区 iclaude 一次 Plan 评审，主 agent 独立复核采纳；真实额度不足时才使用替代 subagent。

## 交付目标

用户能创建易读的全局/项目 agent 定义，确认来源并在当前中心显式绑定 runtime，取得可供下游委派直接使用的内容快照和原生参数。没有默认模型时不覆盖原生配置，不运行任务或管理 skills/MCP。

## 关键决策

- 一个 YAML 一个稳定标识；项目同标识整体覆盖，坏配置明确失败。
- 共享职责可不含个人 runtime ID；个人绑定集中保存在现有 client.sqlite，按来源/连接/认证 namespace 隔离。
- 离线发现与验证不启动服务；在线 check 才解析实际目标，不把旧绑定或模型参数字符串当已验证执行。
- cwd 与项目根分开；下游负责准备实际目录和启动，快照不会因之后配置编辑而变化。

## 任务

### T1 可解释的全局与项目定义

- 状态：已完成
- 交付：严格 YAML 格式、作用域发现、整体覆盖、来源及内容版本，排他模板创建和离线读取/校验 CLI；个人绑定展示由 T2 补齐。
- 依赖：已验收配置与工作区基础
- 验收：空环境可创建；两个作用域互不写入，Git worktree/子目录/非 Git 项目定位明确；空值保留默认，错误不回退。
- 验证：真实文件/Git 工作区测试、CLI 子进程、类型检查，不启动服务或模型。

### T2 个人绑定与委派参数快照

- 状态：已完成
- 交付：集中 SQLite 个人绑定、在线 bind/unbind/check/list --check、ResourceClient 目标组合、定义与解析版本及原生 launchOptions。
- 依赖：T1、已验收全局资源
- 验收：绑定不改共享文件/资源；精确来源、连接和 namespace 隔离，同仓库 worktree 共享绑定；空值不覆盖，Codex/Claude 参数各沿已有 HAPI 字段，隐藏 Runweft MCP，不增加权限或启动目录。
- 验证：真实 SQLite/API/CLI 组合、失效目标与离线引用、跨 flavor 误绑定拒绝、批量探测复用、两类 flavor、旧快照稳定和无任务副作用。

### T3 配套定义验收与使用说明

- 状态：已完成
- 交付：paths/清晰示例与继承说明、配套编译 CLI 的 global/project/local/Hub 组合验收、需求映射。
- 依赖：T2
- 验收：无需实际模型任务，能从创建定义到指定 runtime 的完整解析；不会生成项目资源注册或修改原生配置。通过后同步 Specs 并归档。
- 验证：常规回归、构建、专用编译 Hub/Runner 的实际资源发现与定义解析，token :namespace 后缀及 local/Hub 切换隔离；复用已验证原生执行继承，不冒充远端或模型组合验证。
