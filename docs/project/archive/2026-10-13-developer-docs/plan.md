# 收敛计划

依据 [需求与方案](requirement.md)，按 T1 → T2 串行。用户已授权范围内工程决策与自动本地验收，iclaude 额度耗尽，本次 Plan 用新的 subagent 只读评审；主 Agent 独立判断后落实。

## T1 固定被移除文档的历史引用

交付：四处旧归档链接固定到当前清理前提交，保留标签、正文、锚点与流程状态。

验收与验证：目标 Git blob 和锚点存在，四处差异仅链接目标变化，工作流及 diff 检查通过。

## T2 集中开发必读并精简文档职责

交付：压缩 AGENTS 并直接承接常用开发步骤；缩短根 README，移除 docs/README 和通用 development.md，保留专门的打包发行操作说明；修正当前入口、CI 选择测试示例及 usage 失效锚点。

验收与验证：逐项核对旧约束和独有操作都有合理去处，当前本地链接/锚点有效，历史目标固定。运行既有 CI 选择测试、工作流和 diff 检查；确认包输入、HAPI、原型和生产代码不变，不重跑无关产品/模型验收。
