## 交付目标

截图自然成为会话介绍的一部分，压缩占用高度，去掉保守说明与公开来源标注。

## 关键决策与风险

- 保留既有蓝白样式；截图预览与完整原图分开，通过普通链接查看。
- 新文字仍由 iclaude 提供；全图不改字节，避免为了小预览改坏原图。
- 截图只作辅助说明，不缩小页面正文来挤占空间。

## 任务

### T1 合并布局和精简文案

- 交付：iclaude 评审/文案，紧凑并排预览与原图入口，删除说明和公开来源。
- 验收：前后高度明显缩短，六宽度无溢出，首屏不变，无 JS/键盘可访问完整图。
- 验证：15 项发布检查、构建、Playwright 三页及六宽度前后截图/高度比较、冻结发行输入检查。

### T2 发布与归档

- 交付：main 官网发布、自动线上验收、Specs 同步与 Change 归档。
- 验收：核心/Pages CI 通过；唯一 URL 和正式域名内容及实际显示一致。
- 验证：十文件摘要/MIME、生产浏览器、文档结构与 git 状态。
