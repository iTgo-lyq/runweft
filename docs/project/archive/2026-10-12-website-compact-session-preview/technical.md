# 官网截图紧凑布局

> 状态：已确认
> 依据：用户已明确视觉/文案修正；当前首页截图是独立双卡片，整张长图加大留白，手机改为两张纵向长图。

沿用现有浅蓝背景、蓝色链接、正文系统字体与字阶。把截图移入 #native-experience 的 results-band，文案在左，紧凑双图在右；800px 及以下文案在上、双图仍并排。移除图外双层大卡片、来源、说明和重复图注，只保留短标题与查看完整图片的清晰入口。

预览容器以 CSS 定宽高/比例与 object-fit/object-position 呈现图片的主要内容，不修改两张原图。桌面单张预览目标宽度 140–180px、高度 180–240px；窄屏按可用宽度等比例缩小；点击同一原图链接查看完整界面。两图的尺寸、lazy loading、alt 与焦点保留。保留 #session-screenshots 深链并指向合并后的介绍块。

文案由 iclaude 一次评审后撰写，主 Agent 按原文集成；消息/工具、审批、在线文件与主 Agent 续接的实际边界沿已有指南，不在截图区堆砌声明。原图来源继续保存在开发溯源记录，官网不展示来源文案。

仅修改网站结构/CSS、必要的图注和已有浏览器验收；十文件白名单和图片字节不变。不添加 JS 弹窗或新依赖。Playwright 记录前后高度、首屏/CTA、六宽度、并排、原图/键盘/无 JS；正式部署后检查十文件摘要/MIME和三页浏览器。

采用 iclaude 评审建议：样式限定在 .session-band；三项能力压成左栏短列表；两图最大 180×240，保留可见原图入口和未裁切的焦点框。标题自然换行，预览按各图内容选择 object-position。
