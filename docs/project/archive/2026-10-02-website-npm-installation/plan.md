# 官网统一 npm 安装计划

> 来源：./requirement.md
> 技术方案：./technical.md
> 执行模式：逐任务提交

## 交付目标

官网只提供 npm 安装，小体积静态输出可独立构建，实际安装和网页交互经过自动验收。

## 任务

### T1 统一安装页面与独立静态构建

- 交付：首页/指南/参考、当前使用说明与包内 Skill 源码统一 npm；删除下载产物依赖和旧交互，发行组装适配；更新自动网页验收。
- 验收：无归档/下载入口；独立构建与失败保护；DOM 命令真实 npm 安装、包内 Skill、交互和布局通过。
- 验证：网站 build/Playwright，聚焦发行组装测试，typecheck 和根测试；全部专用环境，不运行模型或修改用户配置。

### T2 同步规格并归档

- 交付：官网构建/验收说明、相关 Specs、验收记录及完整 Change 归档。
- 验收：只记录实际 npm/网页证据，明确未部署/未发布新版本；历史交付不改写。
- 验证：validate-change、文档链接与 diff；逐任务提交，按既有授权推送当前分支。

## 风险与恢复

真实 npm 安装需要网络，只记录已确认结果；网页版本不得当作新的程序候选。文档改变包输入，下一次程序发行重新冻结，原公共包与离线整包不重组。网站错误保留原输出，安装失败不执行后续命令。

按原任务依赖及既有 Plan 顺序迁入；未重新安排历史执行。
