# 隔离预发行卸载测试的原始程序夹具

用户已授权将账号密码改造合入 develop 并发布 npm 预发行。v1.2.0-beta.1 在上传前的完整无模型集成失败，必须修复当前发布阻碍后继续完成授权范围。

首个失败位于 cli-uninstall：compiledCli 在发布验收时返回有效平台包中的真实候选，而原始程序拒绝测试直接对其执行 uninstall --yes。该候选被正确识别为可卸载平台包并删除，后续七项测试随之 ENOENT。原 run 为 39218611839，252 pass、8 fail；五个 1.2.0-beta.1 npm 版本查询均 404，上传步骤未运行。

方案是在测试拥有的临时目录复制一份没有包元数据的独立程序，再验证原始开发程序不可卸载。保留源候选并增加存在性断言，不修改产品卸载行为或绕过发行门禁。失败标签保持不可变，版本和包内说明推进至 1.2.0-beta.2；之后重新执行完整发布流水线。

验收：定向卸载集成对真实平台包运行通过，源候选保持存在，类型/文档/差异检查通过；正式发布结果从 GitHub Actions 与 npm registry 核对。无模型调用，不调用 iclaude。
