# 新版本候选

## 目标与范围

1.2.1 的 npm 上传确认长时间未结束，且只有部分平台包可读取。用户要求遇到异常等待直接发新版本，并停止持续等待。按此授权递增根版本到 1.2.2，合入 develop 和 main 后触发既有发布工作流。

本次为 small：只修改版本号，不改变产品行为、依赖或发布门禁。保留 1.2.1 的标签、回执及已公开包，不覆盖旧版本。取消旧工作流的等待不代表撤销 npm 已接受的上传。

## 方案与验收

- 从干净提交构建 1.2.2 候选，验证版本、安装及必需的五项原生案例；旧版本报告不作为新版本的冻结输入证据。
- 本机 Claude Code 验收使用 claude-glm、glm-5.3 和 medium effort，认证仅复制到专用现场。
- 原有 CI 继续负责公开包验收及 latest 晋级。触发后向用户提供运行链接，明确未确认发布成功，不持续轮询上传进度。
- Change 验收覆盖版本变更及本地候选；外部发布状态由 Actions 保存，不编写额外发行报告。
