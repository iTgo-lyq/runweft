# 1.1.7 正式发布版本准备

用户明确要求正式发布一次，实测官网/npm 并行后的总耗时与阶段分布。当前 main 已包含并经独立评审验证的并行发布流程；本 Change 仅准备下一规范稳定版本 1.1.7，不修改程序行为或发布门禁，规模 small。

将根版本和包内使用说明中的当前安装版本同步到 1.1.7，检查版本引用、稳定站点构建、相关脚本、文档与工作流，沿用户发布授权归档并合入 main。继续使用固定 Bun 1.4.2 和原 HAPI pin。纯版本准备不重复触发独立预检；正式 tag 发布自身执行完整打包、上传前检查、公共集成与四平台安装/卸载以及官网验收。

验收为版本及安装提示一致、相关本地检查通过、源码干净可冻结。正式发布在归档合入后推送不可变 v1.1.7，结果与时间记录另存 docs/releases，不回写本归档，也不把准备通过写成发布成功。

沿用已接受的官网可以暂时先于 npm 的取舍。以 GitHub 正式 run 创建为计时起点，分别记录 npm 就绪、官网就绪、最终汇总完成；并行阶段不相加，排队、npm 可见性、实际上传及失败恢复分别统计。未知/失败先诊断再定向续验，不盲目重发已有包或移动 tag。
