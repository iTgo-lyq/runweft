## 目标与范围

用户确认现有官网框架和样式可用，要求优化内容组织和文案，让首次访问者一眼理解产品并容易上手；明确要求 iclaude 参与，并于本轮追加要求：官网文案全部由 iclaude 重新编写，包括已修改的首页。主 Agent 不创作或润色面向用户的文案。目标读者是已经使用 Codex 或 Claude Code、希望委派开发任务的人。
