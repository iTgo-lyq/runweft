# 全局 Subagent 看板

`runweft open` 打开当前连接的 `/runweft/`，`--hapi` 打开原生 HAPI。CLI 检查看板能力，不兼容时提示更新或使用原生入口。本地模式沿既有服务启停规则，Hub 客户端访问选定中心。页面、脚本、样式内嵌于程序，不依赖源码目录、CDN 或另一个前端服务。

原生 HAPI Web/PWA 在浏览器未保存有效语言选择时默认简体中文；有效的 en / zh-CN 选择继续生效。在「设置 → 通用 → 语言」可切换 English 或简体中文，选择保存在当前浏览器的 hapi-lang 并在刷新后保留。缺少中文文案时沿 HAPI 原有英文回退。更新配套程序后需重启服务加载新版页面。

## 范围与来源

看板列出当前 HAPI JWT namespace 内所有工作区及父会话的委派任务，不要求浏览器所在机器运行 Runner。查询是只读投影，不调用模型、探测 runtime、推进任务或修改业务状态。主宿主退出后仍可查看持久记录；看板不恢复主宿主。

每行显示 Agent 定义名称、父工作区/会话、机器、runtime、执行目录模式、当前轮次状态以及独立的执行/代码/附件状态。展开显示原生阶段、停止事实、观察与更新时间、结果摘要、需关注原因和代码成果下一步；有真实 HAPI session ID 才提供详情链接。对话、审批及机器管理沿 HAPI 页面，不提供额外调度或修改操作。

执行未知保持未知，进程关闭与成果交付分别表达。共享目录的代码交付为不适用；停止但可续接的 session 不视为异常。机器离线或库存未知时，未完成任务提示状态可能过期；已确认完成的记录保持完成事实。

## 认证与刷新

沿同源 HAPI access token 登录，无额外账号。成功登录复用 HAPI 的本地存储 key；JWT 只存在页面内存，过期时重新认证并重试读取一次。持久认证失败回到连接表单。URL 中的 token 读取后立即移除，导航链接不带凭据；HAPI 链接固定当前 origin 的 hub，避免被浏览器旧连接覆盖。

页面每 5 秒在可见状态刷新，支持手动刷新；新筛选替代旧请求，旧响应不覆盖新结果，刷新保留展开条目。请求失败保留上次成功数据及时间，并明确显示错误。区分首次未连接、尚无任务、筛选无匹配和认证失败。报告经纯文本渲染并限制长度，列表不包含任务输入、定义 instructions、完整原生输出或凭据。

## 筛选与接口

GET `/api/runweft/tasks/overview` 按已有身份认证，不接受调用方覆盖 namespace 或 parent 身份。支持父工作区 `workspace`、父会话/机器 `parent`、执行 `status` 与 `page/limit`；默认每页 50 条，上限 100，拒绝未知或重复参数。

查询复用委派任务领域的状态，优先展示待处理/未知、运行中，再按更新时间和 ID 排序。机器库存读取有界，失败返回已有任务与库存错误；不把库存不可用解释为任务成功。页面提供桌面和窄屏布局、可见键盘焦点与详情展开。
