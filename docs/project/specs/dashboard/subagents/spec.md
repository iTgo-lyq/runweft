# Hub 页面与任务总览

open 默认进入 /hub，提供独立身份领取/导入、空间成员管理及加密连接确认，以及任务、机器、Runtime、Agent、仓库和本人选择后台。旧 /runweft 看板不在默认集中网关开放。桌面为身份/空间侧栏与资源工作台，窄屏采用横向导航和单列表单。

按钮消费服务端 permissions；直接 API 同样校验权限。机器/runtime 展示所属人、共享/登记、在线与凭据状态，初始登记和轮换交由目标机器上的 Agent/CLI。Agent 支持完整定义、版本条件编辑、历史、分享和概要治理；管理员不能读取或编辑他人的私有定义。仓库支持名称、别名和登记，本人 checkout 只读，真实 Git 绑定由本机 Agent 完成。

本人空间/仓库选择和 runtime override 与其他用户独立；失效选项保留原 ID 和原因，不自动回退。Agent/仓库创建将请求 ID 与内容摘要保存在标签页，响应未知先查询回执，显式重试复用同一请求。切换空间或身份清空旧数据，刷新/报错不自动创建身份。

GET /api/runweft/tasks/overview 按当前用户/空间 JWT 读取本人任务，支持 workspace、parent、status、page/limit（默认 50，最多 100），拒绝未知和重复参数。身份/空间不能由查询参数覆盖，Agent 分享不公开任务。查询只读持久投影和机器事实，不探测模型、推进任务或修改状态。

总览区分原生执行、未确认启动、停止、工作区/文件/代码交付与留存；离线库存保留任务事实，不伪造在线或完成。最早未结束轮次优先于排队续轮，报告有界。当前可以 task list/show 查询。主宿主退出后持久记录保留，不恢复主宿主。

任务为默认页，支持筛选/分页；GET /api/runweft/tasks/:id/details 按本人空间读取轮次、配置快照、分页报告、文件和代码状态，不要求浏览器伪造父宿主。报告按文本展示。停止、续接、取回和清理由 Agent/CLI 完成，页面提供任务 ID 与维护说明。

HAPI 原生消息、审批和文件组件由 HAPI 维护，后台先验证会话可读，再以独立标签页当前空间短 JWT 打开同源详情/文件深链接。凭据不进入 URL 或全局 localStorage；过期返回 Hub 重新打开，不无限续期。受管任务的重新启动、输入和模型修改使用 Runweft 任务入口；共享 runtime 不提供任意终端。授权细节见[执行通道](../../execution/access/spec.md)。

原生 HAPI Web/PWA 在浏览器未保存有效语言选择时默认简体中文；有效的 en / zh-CN 选择继续生效。在「设置 → 通用 → 语言」可切换 English 或简体中文，选择保存在当前浏览器的 hapi-lang 并在刷新后保留。缺少中文文案时沿 HAPI 原有英文回退。更新配套程序后需重启服务加载新版页面。
