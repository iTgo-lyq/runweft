# Hub 页面与任务总览

open 默认进入 /hub，提供账号注册/登录及确认即激活的 CLI 连接。工作台有任务、机器、Runtime、Agent、仓库、我的选择、成员和账号设置八个入口，任务为默认页。旧 /runweft 看板不在默认集中网关开放。桌面为账号/空间侧栏与列表、检查器，窄屏使用导航抽屉与全屏详情，关闭抽屉归还焦点，导航后聚焦页面标题。外观支持浅色、深色和跟随系统，并提供减少动态效果与透明度的退回样式。

Hub 使用 React、Radix/shadcn 与 Tailwind，组件、设计 token、图标和交互由仓库内 `packages/ui` 维护，视觉规范见 [DESIGN.md](../../../../packages/ui/DESIGN.md)。原型独立实现页面、内存数据和演示控制，只共用 UI 库；原型自身改动不改变正式页面。前端静态打包后嵌入单二进制，不依赖 CDN、外部字体或额外前端服务。Hub CSP 保持同源脚本和网络连接、禁止外部资源，`style-src 'self' 'unsafe-inline'` 允许组件插入样式；脚本不允许内联或 eval，报告与用户内容按文本渲染。

按钮消费服务端 permissions；直接 API 同样校验权限。机器/runtime 展示所属人、共享/登记、在线与凭据状态，初始登记和轮换交由目标机器上的 Agent/CLI。Agent 支持完整定义、版本条件编辑、历史、分享和概要治理；管理员不能读取或编辑他人的私有定义。仓库支持名称、别名和登记，本人 checkout 只读，真实 Git 绑定由本机 Agent 完成。

成员页按权限管理角色、邀请和空间名称；存在其他所有者时允许所有者降低自己的角色，并同步工作台权限，最后一位所有者不可降权或退出。邀请只在生成后的对话框中显示一次，可复制、可选中文本，不提供下载；关闭后丢弃页面状态，待使用邀请可撤销。

本人空间/仓库选择和 runtime override 与其他用户独立；失效选项保留原 ID 和原因，不自动回退。Agent/仓库创建将请求 ID 与内容摘要保存在标签页，响应未知先查询回执，显式重试复用同一请求。切换空间或身份清空旧数据，刷新/报错不自动创建身份。同一身份/空间刷新失败保留已有成功内容并显示错误；初次加载失败明确呈现。详情刷新保留轮次、报告位置和展开状态；清空后的迟到响应不能恢复旧视图。

根会话刷新、外部深链接与空间切换只应用最新有效选择；旧请求的成功或错误不能恢复旧空间、退出后的账号，或使新账号过期。空间 JWT 等待期间上下文变化时不再发送旧写操作。明确退出浏览器、修改密码和退出全部环境按账号处理，空间切换不能丢弃其成功结果；失败时保留登录并明确显示错误。请求失败不自动重试，写入结果未知时先刷新或查回执核对。

GET /api/runweft/tasks/overview 按当前用户/空间 JWT 读取本人任务，支持 workspace、parent、status、page/limit（默认 50，最多 100），拒绝未知和重复参数。身份/空间不能由查询参数覆盖，Agent 分享不公开任务。查询只读持久投影和机器事实，不探测模型、推进任务或修改状态。库存查询有3秒截止，失败仍返回持久事实及明确错误；请求取消或撤权不能被降级成成功响应。

总览区分原生执行、未确认启动、停止、工作区/文件/代码交付与留存；离线库存保留任务事实，不伪造在线或完成。最早未结束轮次优先于排队续轮，报告有界。当前可以 task list/show 查询。主宿主退出后持久记录保留，不恢复主宿主。

任务为默认页，支持筛选/分页；GET /api/runweft/tasks/details/:id 按本人空间读取轮次、配置快照、分页报告、文件和代码状态，不要求浏览器伪造父宿主。报告按文本展示。停止、续接、取回和清理由 Agent/CLI 完成，页面提供任务 ID 与维护说明。

HAPI 原生消息、审批和文件组件由 HAPI 维护，后台先验证会话可读，再以独立标签页当前空间短 JWT 打开同源详情/文件深链接。凭据不进入 URL 或全局 localStorage；到期或SSE收到401先清本标签页短凭据，再返回Hub显式重新打开，不无限续期。受管任务的重新启动、输入和模型修改使用 Runweft 任务入口；共享 runtime 不提供任意终端。授权细节见[执行通道](../execution/access/spec.md)。

原生 HAPI Web/PWA 在浏览器未保存有效语言选择时默认简体中文；有效的 en / zh-CN 选择继续生效。在「设置 → 通用 → 语言」可切换 English 或简体中文，选择保存在当前浏览器的 hapi-lang 并在刷新后保留。缺少中文文案时沿 HAPI 原有英文回退。更新配套程序后需重启服务加载新版页面。

账号页支持注册、登录、显示名称、改密码、当前退出、全端退出、登录环境列表/撤销和部署者辅助密码恢复。新用户在一页输入用户名和密码并注册连接，显示名称与初始空间取默认值；已有用户可登录并连接。界面不显示 token 输入、备份、下载或轮换；密码和 CLI 凭据不进入可复制接入提示。

CLI task show 提供带空间、任务和轮次的无秘密深链接。未登录先保存定位，再经账号登录恢复原任务；成员资格及任务所有权仍由服务端校验，链接不授予权限。原生新标签只保留受限短 JWT，不继承账户会话或连接请求。
