# 资源范围与授权

机器/runtime 为 Hub 全局对象，Agent 为独立业务配置。资源所有权与向空间授予的使用权分别保存；不同 cwd 使用相同登记，不同 Hub 不按名称借用引用。完整数据模型和接口见[Hub 资源归属](../ownership/spec.md)。

local/hub 不再限制业务目标为本机；目标由当前用户、空间和 Agent 选择决定。shared 必须在发起机器；远端只允许 worktree，主目录须为 Git 仓库。来源机器必须属于调用者。

用户通过身份 token 换取受限空间 JWT，Runner 使用自己的机器凭据；公开请求不携带私有 HAPI root。调用与实际执行分别复核主体、成员资格、资源登记/分享和对象绑定。默认集中网关不提供旧 namespace 配置入口，旧数据不自动认领。
