# 原型设计说明

视觉与交互遵循[项目设计规范](../ui/DESIGN.md)。本包正在改用 [UI 库](../ui/README.md)；在迁移完成前，`src/style.css` 与 `src/ui/` 仍是已验收版本的实现。这里只记录原型特有的例外：

- 受限 iframe（仅 `allow-scripts`）不允许原生表单提交，本包在本地校验后分发提交事件；也无法写剪贴板，邀请和接入说明只显示可选中的文本。
- 演示控制（右下角“演示”）切换数据场景、空间角色、外观和账号场景，不属于产品界面，样式只在本包内。
- 示例版本号、哈希和路径都是虚构的；原型不证明任何真实执行或接口行为。
