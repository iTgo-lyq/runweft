# Runweft Hub 原型设计规范

依据：[Hub 样式](../../src/hub/style.css)、[页面骨架](../../src/hub/page.html) 及本包 `src/ui/` 页面。初次抽取来自 `23ca1d4`。目标是让协作成员检查已有资源配置和任务交互，采用现有 Hub 的蓝灰工作台样式。

## 色彩与字体

| 用途 | 值 | 应用 |
| --- | --- | --- |
| 背景 / 表面 | #f3f6fa / #ffffff | 页面 / 卡片与控件 |
| 正文 / 辅助 | #213148 / #53657e | 内容 / 提示与元数据 |
| 操作 | #245ac7 | 按钮、链接、焦点与选中导航 |
| 边界 | #d8e1ed | 分隔与表单边框 |
| 待处理 | #a15b00 | 需要处理的状态条 |

正文使用系统字体、PingFang SC 回退，14px / 1.6。标题使用 Avenir Next、PingFang SC、system-ui：H1 32px/650（移动端 27px），H2 22px/650，H3 16px/650。代码使用 SFMono-Regular、Consolas、monospace，12px。不下载外部字体。

## 布局

主容器最大 1288px，桌面横向内边距 24px；工作区为 300px 侧栏和弹性内容，间距 32px。850px 以下缩小侧栏；680px 以下单列、横向内边距 16px。资源表单与事实列表双列，在 680px 以下单列。资源导航横向滚动，表格在容器内滚动。

按钮及输入圆角 5px，卡片边界平直、左侧蓝色 3px。对话框圆角 8px，最大宽度 640px，使用遮罩和轻阴影。资源列表间距 18px；卡片内边距 20px，移动端 16px。

## 交互与状态

复用本包 `src/ui/console.js` 的表单、按钮、卡片、事实列表与折叠区域。主要操作蓝底，次要操作白底，治理操作文字按钮并确认。原生 details、dialog、label 和 button 保留键盘行为；可见焦点为 3px 蓝色轮廓；状态反馈使用 aria-live。禁止用颜色作为唯一状态信号。

本次新增演示工具条用于切换正常、空数据、机器离线、加载失败；所有变化只在内存中生效。身份入口仅接受演示 token `demo`，原生详情以示例对话框表示。工作台 iframe 不具备剪贴板与下载权限，因此演示 token 只显示，不提供复制/下载按钮。产品的认证、真实执行和网络恢复不由原型承诺。

受限 iframe 不允许原生 form 提交。`src/forms.js` 将提交按钮/回车转为本地 submit 事件，先调用浏览器字段校验；dialog 表单直接关闭并返回选择。此适配只用于原型，不改变产品提交方式。

## 账号与首次连接

独立入口 `src/account-onboarding.html` 沿用以上蓝灰色值、系统字体、5px 控件圆角及可见焦点；桌面为账号表单和连接摘要两列，720px 以下单列并优先显示设备核对信息。注册只收用户名与密码；登录空间选择按需出现。明确显示授权效果与“已授权”结果，不把它表达为本机执行就绪。演示工具条用于审查异常与账号管理，不属于产品首次接入步骤。
