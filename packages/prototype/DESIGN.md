# Runweft Hub · 蓝色轻玻璃原型

本次原型依据用户授权重新设计：现代、易读、易操作、减少冗余，保持蓝色，局部使用克制的苹果液态玻璃风格。来源为现有 Hub 原型（最初抽取自产品提交 `23ca1d4`）。本次只输出原型，不代表已实现或验证产品后端。

## 视觉系统

背景采用雾蓝 `#f1f5fb`，左侧有柔和蓝色光晕。正文为实底白色 `#ffffff`，主文字 `#172841`，列表主信息 `#3a4e69`，次要内容采用深灰蓝。主色 `#2862e9`，主要操作使用 `#4484f8 → #2862e9 → #2255d6` 的轻微渐变。成功、警示、失败分别采用绿色、琥珀色、玫红色的低饱和底色，并配合文字及状态点。

液态玻璃主要用于侧栏、空间切换器、选中导航和浮层，以半透明白色、边缘高光、局部渐变和 blur/saturate 形成精致感；表格与长文本保持实底。缺少 backdrop-filter 时回退为不透明表面。避免在每张资源卡上重复发光、渐变或动画。

字体使用系统界面字体与中文系统回退，不请求外部字体。页面标题 30px，卡片标题 14–17px，任务主信息 13px，导航 13px；元信息更小但提高对比。桌面侧栏 228px，主内容左右留白 38px；阅读区圆角 18px，侧栏 22px，输入控件与按钮 8–10px。

## 信息与交互

固定导航分为工作空间、执行资源、空间设置；身份和空间管理集中至独立入口。顶部保留面包屑、全局搜索、通知与身份入口。低频演示工具收进页脚入口。

任务页首屏提供任务数量和状态筛选，再以表格显示标题、状态、Agent/Runtime 和更新时间。ID、配置与环境放入详情折叠区，报告和下一步操作优先。抽屉详情提供概览、执行记录和附件，支持轮次切换。资源使用统一卡片，创建与编辑在弹窗完成；成员邀请、默认选择、身份修改、空间切换均可演示。

shadcnuikit MCP 查询了 `project-list`、`data-table2` 和 `empty-state3`，参考列表分层、筛选、详情和空态模式。Kit 源码为 React/Next.js/Tailwind；本原型保持原生 DOM，因此使用本包实现，不声称已安装 Kit 的 React 组件。产品层不新增自动编排器，也不在原型中启动真实执行。

## 响应式与可访问性

760px 以下侧栏收起，通过工具栏菜单打开；正文直接可见。任务表保留任务和状态，其他信息在详情中查看。1000px 以下资源网格改为两列，760px 以下单列；834px 平板保持桌面导航但缩减表格列。验收尺寸为桌面 1440×1000、平板 834×1112、手机 390×844。

使用原生 button、input、select、dialog，保证标签与可见焦点；详情 Tab 支持方向键、Home/End；Escape 关闭弹窗，菜单支持遮罩点击关闭。图标操作均命名，装饰 SVG 隐藏于辅助技术，状态不只依赖颜色。减少动态效果偏好关闭动画与过渡。

所有数据和更改只在内存中保存，刷新/重置恢复。`sandbox="allow-scripts"` 无表单权限时使用既有 forms.js 分发本地提交并保留浏览器字段校验。禁止真实接口、凭据和浏览器持久存储。保留八个入口与 OpenFolio ready/error 握手。
