# Runweft 设计规范

本规范是 Runweft 界面的唯一视觉依据。Hub 产品（`src/hub/web`）与原型包（`packages/prototype`）都通过本目录的 UI 库实现它，用法见 [README](README.md)；原型包只在自己的 DESIGN.md 记录原型特有的例外。设计来源见 Change [Hub 前端交互与样式重构](../../docs/project/changes/hub-glass-prototype/requirement.md)。

## 方向

依据三份材料，取舍以需求文档为准：

- **气质**：用户提供的 Craft 视觉与交互总结（另一 Agent 整理）——安静、内容优先、工具随时可用。
- **材质**：Apple 对 Liquid Glass 的定位——控件和导航是浮在内容之上的功能层，并向内容让位（[Apple Newsroom，2025-06-09](https://www.apple.com/newsroom/2025/06/apple-introduces-a-delightful-and-elegant-new-software-design/)）。
- **布局思路**：shadcnuikit 的页面与区块，见[布局参考](#布局参考)。只借鉴结构和状态处理，不安装、不复制其 React 源码。

落地原则：冷调中性色做框架，蓝色只做强调；侧栏融入窗口背景，内容是一块完整的实底表面；玻璃只出现在浮动控制层；少用边框和分割线，用留白、低对比背景和字重建立层级。

## 色彩

令牌定义在 `src/styles/tokens.css` 的 `:root`，Tailwind 主题映射在 `src/styles/index.css`；深色重新分层而不是反色。

| 用途 | 浅色 | 深色 | 说明 |
| --- | --- | --- | --- |
| 窗口背景 `--canvas` | `#edf0f5` | `#0d1015`（手机 `#000`） | 侧栏直接放在上面 |
| 内容表面 `--surface` | `#ffffff` | `#161a21`（手机 `#000`） | 阅读、表格、表单 |
| 次级表面 `--surface-2` | `#f5f7fa` | `#1c2129` | 摘要块、开关组、代码块 |
| 正文 / 次要 / 辅助 | `#141b26` / `#4b5768` / `#697486` | `#e8ecf2` / `#a9b2c0` / `#848fa1` | 辅助文字仍满足正文对比 |
| 强调 `--accent-fill` | `#2b5fe3` | `#3d6ff0` | 主要按钮、选中、焦点；深色文字用 `#6b97ff` |
| 成功 / 警示 / 失败 | `#157a4f` / `#975800` / `#bf3530` | `#4cc38a` / `#f0b443` / `#ff746a` | 配低饱和底色 |
| 未确认 `--unknown` | `#6a4cb5` | `#b9a3ff` | 只用于“执行未确认”，与失败区分 |

状态从不只靠颜色：任务状态同时有图标（进行中、需要处理、执行未确认、已完成、失败、已停止各有图形）、文字和颜色。

## 玻璃

`.glass` = 半透明底 + 中性高光渐变 + 背景模糊 + 顶部高光与细边。按 Apple 的说明，小控件的玻璃更薄、尽量让内容透出，面积大的元素更厚（[Meet Liquid Glass，WWDC25](https://developer.apple.com/videos/play/wwdc2025/219/)）。玻璃本身不着色，蓝色只留给主要操作。

| 厚度 | 用在 | 浅色 | 深色 |
| --- | --- | --- | --- |
| 薄（`--bar-*`） | 内容区顶部的浮动工具栏 | 白色自上而下 40% → 80% 渐变，`blur(4px)` | 深灰自上而下 42% → 82% 渐变，`blur(4px)` |
| 常规（`--glass-*`） | 菜单、筛选弹出层、底部提示、手机导航抽屉、账号页“核对连接请求”卡片，以及原型的演示控制 | 约 75–85% 白，`blur(22px) saturate(175%)` | 约 60% 深色 |

工具栏的材质参照 [Craft 博客页](https://www.craft.do/zh-CN/blog/craft-update-3-7-0)导航的实测样式：上部更通透、下部更乳白，轻模糊保留背后内容的轮廓；1px 渐变高光描边由遮罩挖空的伪元素绘制，上沿明显、中段消失、底沿再出现；阴影是一层大范围柔影加一层贴边小阴影，常驻不随滚动变化。外形是高 52px 的胶囊，内部按钮同为全圆角。没有照搬 Craft 920px 的最大宽度，工具栏仍与内容表面同宽，面包屑和页面标题左对齐。深色用同样的结构：底色取比内容表面略亮的深灰，高光描边更弱，阴影更深，在深色背景上仍能看出浮起。通透感只靠背景透明度控制，不给整个工具栏设 `opacity`，以免文字和按钮一起变淡。

不用于：列表、表格、报告、表单和对话框正文，也不在玻璃上再叠玻璃。检查器头部使用不透明度 88% 的表面加模糊，只为滚动时保持标题可读。浏览器不支持 `backdrop-filter` 或用户开启“减少透明度”时，`.glass` 退回不透明表面，对话框背景也不再模糊。Apple 的折射（lensing）效果需要 `backdrop-filter: url()` 配合 SVG 位移滤镜，Safari 和 Firefox 不支持，原型不做。

## 字体与尺寸

不请求外部字体。正文用系统无衬线字体（`-apple-system`、PingFang SC 等），标题用 `ui-rounded` 回落到系统字体，代码与标识用系统等宽字体。

| 层级 | 规格 |
| --- | --- |
| 页面标题 | 26px / 680，手机 23px；账号页 29px |
| 检查器与对话框标题 | 19px / 680 |
| 区块标题 | 16px / 650；检查器小节 13px / 600 次要色 |
| 列表主信息 | 14.5px / 600；正文 13.5–14px |
| 报告阅读 | 15px，行高 1.85，最大 68 个字宽 |
| 元信息 | 12–12.5px，时间使用等宽数字 |

圆角随尺寸递增、嵌套同心：控件 9–10px、行与卡片 12–16px、检查器 16px、内容表面 18px、对话框与账号卡 22–24px，标签与胶囊为全圆角。按钮高 34px（小号 30px），触屏下提高到 40/36px。

## 布局

| 尺寸 | 结构 |
| --- | --- |
| 桌面（≥1100px） | 252px 侧栏 + 8px 内缩的内容表面；列表与 500px 检查器并排，打开时列表平滑让出宽度 |
| 平板（761–1099px） | 220px 侧栏；检查器变为右侧浮层，背后加遮罩 |
| 手机（≤760px） | 内容铺满，导航收进玻璃抽屉；检查器全屏；页面操作按钮占满宽度 |

窄列表用容器查询隐藏低优先级列（机器的“此空间”“最后活动”，Runtime 的“此空间”“工具版本”）。页面底部和检查器底部留出空间，避免浮动控件（如原型的演示控制）长期遮挡最后的操作。

## 交互

- **选中与打开**：键盘焦点（方向键在列表中移动）表示选中；打开的条目有浅蓝底和左侧细线，检查器同时出现。Escape 关闭检查器并把焦点还给原条目。
- **低频操作**：ID、凭据、取消登记、治理等收进检查器下方或“更多操作”菜单；风险和权限提示始终可见。
- **就地编辑**：名称类字段（机器、Runtime、仓库、空间、显示名称）在原处编辑；Agent 定义在检查器内切换为编辑表单，保存生成新版本。
- **确认**：会撤回权限、停止执行或不可撤销的操作先确认，确认文案写清影响范围。
- **反馈**：成功用底部轻提示；失败、结果未知、离线用页内横幅并给出下一步；刷新失败保留已读内容。
- **快捷键**：`/` 聚焦“在本页查找”；Escape 关闭菜单、对话框、检查器和手机导航。
- **动效**：160–280ms，只用于展开、切换和布局变化；开启“减少动态效果”时关闭。

## 标志元素：纬线

Runweft 的“weft”是纬线。原型用一种短虚线“织线”表达真实的先后关系：

- 任务检查器中的轮次：每轮是线上的一个结，当前轮实心蓝色，已结束为绿色描边，进行中为虚线描边。上下两股错位的虚线构成织纹。
- 列表中的执行关系：机器 → 原生工具 → 轮次。
- 账号页的接入步骤和“我的选择”的解析顺序。

只在关系确有顺序时使用，不作装饰。

## 无障碍

按钮、输入框、下拉和 details 使用原生元素；对话框、确认框、菜单、弹出层、开关、分段与标签页的键盘行为由 Radix 提供：分段与标签页支持方向键，菜单支持方向键、Home/End、按字母跳转和 Escape，对话框与浮层关闭后焦点回到打开它的元素。图标按钮都有名称，装饰图形对辅助技术隐藏，状态变化通过 `aria-live` 区域播报。输入框使用细边框加浅底，边界对比度偏低，产品落地时需复核。截图和自动检查不等于完整无障碍合规。
